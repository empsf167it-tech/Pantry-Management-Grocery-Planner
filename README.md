# PantryFlow — Static SaaS Website

A premium frontend-only Pantry Management & Grocery Planner website.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services / Features
- `login.html` — Login UI
- `register.html` — Registration UI
- `dashboard.html` — Interactive static dashboard

## Responsive breakpoints
- 368px mobile
- 768px tablet
- 1024px desktop/tablet
- 1440px large desktop

The CSS is mobile-safe and designed to prevent horizontal overflow.

## Important
This is intentionally a static frontend. Login/register are demo flows and do not connect to a backend or database.

Open `index.html` in a browser, or use VS Code Live Server.
